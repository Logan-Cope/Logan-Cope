### Hi, I'm Logan

I'm a software engineer building AI agents that do the searching, sorting and drafting while a person approves what matters. Everything below runs on synthetic data, has tests in CI, and works without an API key.

### What I've built

- **[deal-radar](https://github.com/Logan-Cope/deal-radar)**: agents find underpriced items and check them against the market. A person approves every buy. Python radar plus a Next.js ledger with a Claude note reader. [Live demo](https://deal-radar-ledger.vercel.app)
- **[slate-tracker](https://github.com/Logan-Cope/slate-tracker)**: food, lifts and body weight in one phone app, with a Claude nutrition-label reader held to an eval written first. [Live demo](https://slate-tracker-demo.vercel.app)
- **[prompt-trap-scan](https://github.com/Logan-Cope/prompt-trap-scan)**: finds text on a web page that is aimed at an AI and hidden from a person. 24 of 24 planted traps found, against 4 of 24 for a naive check.
- **[reforge](https://github.com/Logan-Cope/reforge)**: agentic video RAG that rebuilds a reference reel beat by beat from your own footage. Hybrid retrieval beats vector-only search (precision at 5 from 0.497 to 0.776). [Live demo](https://reforge-demo-ashen.vercel.app)
- **[feedback-to-pr](https://github.com/Logan-Cope/feedback-to-pr)**: in-app feedback becomes a GitHub issue, one label turns it into a PR built by Claude in a sandbox, and a person merges it.
- **[cumulus](https://github.com/Logan-Cope/cumulus)**: RAG over documents with cited answers.
